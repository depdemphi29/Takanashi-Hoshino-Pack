# Takanashi-Hoshino-Pack
Một bản Texture Pack được làm bởi [depdemphi](https://discord.gg/YP8A74hz) (yêu cầu bởi [NhaT](https://www.facebook.com/share/1NRtwGuCP2/))

- Được lấy cảm hứng thiết kế texture của Spectra/Weebify
- Nhân vật [Takanashi Hoshino](https://bluearchive.wiki/wiki/Hoshino) trong [Blue Archive](https://bluearchive.nexon.com/home)

> **Note:** Bản texture pack đã lỗi thời và không bảo trì nên nó chỉ mang mục đích lưu trữ và một số texture sẽ bị lỗi file do những file mod đó đã lỗi thời và file vanilla của GD cũng vậy nếu như GD cập nhật một phiên bản mới và thay đổi những file đó
